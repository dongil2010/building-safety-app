1. 앱 개요 및 시작하기

본 앱은 건축물 안전점검 현장에서 결함 위치도, 상태조사표, 비파괴조사, 통계, 보고서(PDF·HWPX)를 하나의 데이터로 관리하는 PWA(웹앱)입니다. Android 현장앱은 Capacitor WebView로 동일 웹을 엽니다.

화면 구성

탭역할
홈현장·회차·동 선택, 건축물 등록·수정, 백업, 설정
결함위치도 작성층별 도면에 핀·영역·화살표 마킹
상태조사표조사표 편집, 사진 앨범, 엑셀·한글 입출력
통계층별·전체 결함 종류 집계, 최대 균열폭
비파괴조사강도·탄산화·기울기·변위·균열 모니터 등

건축물을 선택하기 전에는 결함·조사·통계·NDT 탭이 비활성입니다. 먼저 홈에서 점검 대상을 등록·선택하세요.

2. 로그인·회사 가입·동기화

로그인 / 가입

  1. 앱 실행 → 기존 계정 로그인 또는 신규 가입.
  2. 점검자: 회사명 검색 → 가입 코드 입력 → 가입 신청 → 관리자 승인 대기.
  3. 회사 대표: 회사 대표로 신규 등록 후 직원 계정 승인(가입 승인 버튼).

비밀번호 분실 시 비밀번호 재설정(이메일 링크)을 사용합니다.

동기화

  • 데이터는 Firebase에 자동 동기화됩니다. 헤더 온라인 표시로 연결 상태를 확인합니다.
  • 사진·도면은 IndexedDB에도 저장되어 오프라인에서도 열람 가능(사전 온라인 캐시 필요).
  • 최신 웹 반영: 홈 설정 → 새로고침 (GitHub Pages 배포 후).
  • JSON 데이터 백업 / 백업 불러오기로 전체 복원 가능(PC).

3. 홈 — 건축물 등록·관리

현장·회차·동 탐색

홈 화면은 현장 → 점검 회차 → 동(건물) 순으로 카드를 눌러 들어갑니다. 검색창으로 현장명·주소·담당자를 찾을 수 있습니다.

건축물 등록

  1. 우하단 + 현장 추가하기 (FAB).
  2. 빈 등록 또는 다른 점검에서 가져오기 선택.
  3. 현장명, 단일/여러 동, 주소, 담당자, 점검 종류·년도·반기, 시설물 종별, 준공일 입력.
  4. 층별 도면(PDF·이미지) 업로드.
  5. 건축물 등록 완료 → 해당 동 카드 선택 후 점검 시작.
최근 개선: 건축물 등록 모달도 수정 모달과 같이 본문 스크롤이 되도록 통일했습니다. 내용이 길어도 아래까지 스크롤·드래그할 수 있습니다.

현장 정보 수정

  • 건물 카드의 수정 버튼 → 현장 정보 수정 모달.
  • 도면 재업로드, 다른 점검 데이터 병합, 회차 추가, 동 추가, 휴지통 이동.
  • 전경사진(헤더): 건물 전경·외관 사진(결함 사진과 별도).

기타 홈 기능

  • 점검 수행회사 이름 — 보고서 표지·헤더에 사용.
  • 휴지통 — 삭제 건물 30일 보관 후 복원·영구삭제.
  • 휴대폰으로 촬영해서 바로 받기 — QR 연동으로 PC 결함 입력 중 사진 수신.

4. 결함위치도 — 도면 마킹

기본 조작

  • 점검 층 선택 후 도면 표시.
  • 선택(PAN): 이동·확대, 핀 선택, 드래그로 다중 선택(Ctrl+드래그로 추가).
  • 핀 마킹(MARK, D): 클릭·드래그로 번호 박스+화살표 위치 지정 → 결함 입력창 열림.
  • 영역 마킹(AREA, A): 사각형·타원·다각형 영역 + 내부 필기(선·도형·자유선).
  • 되돌리기/다시 실행 (Ctrl+Z), 일괄 수정, 선택 삭제, 전체 초기화.

좌측 결함 목록

현재 층 결함 목록·분류 필터(기둥·벽, 보·슬래브, 비구조, 마감, 개구부). 같은 번호의 여러 화살표는 목록에서 한 행으로 묶여 표시됩니다.

우측 패널

  • 스타일 설정 — 카테고리별 핀·화살표 색·크기·모양.
  • 위치도 범례 — 범례 항목 편집, 도면 위 드래그·크기 조절.
  • 크기 슬라이더 — 핀·화살표·지시선 (전체층 적용 가능).
  • 고급 필터 — 점검 회차·연도·부재·손상 유형·중요/중점관리 필터.

모바일

  • 우측 레일: 목록, 선택, 핀, 영역, 그리기.
  • 핀·화살표 이동: 0.3초 길게 누르기 후 드래그.
  • 목록 OFF 시 선택 결함만 도면에 팝업 표시.

5. 결함 핀 수정 (최신 기능 포함)

도면에서 핀을 찍거나 목록·핀을 탭하면 결함 핀 수정 서랍(모달)이 열립니다. 입력은 자동 적용되며 닫기만 누르면 저장됩니다.

입력 항목

  • 구조 분류, 부재 명칭, 결함 종류, 발생 원인 (⚙로 항목 추가·삭제)
  • 균열 폭·길이·개수, 규모, 상세 위치(음성 입력 가능)
  • 접합부 위치 조합, 영역 채움·테두리·회전(영역 마킹)
  • 체크: 진행중, 누수, 개구부 균열, 전회차, 중요, 중점관리
  • 사진: 전차(읽기) / 현차(촬영·추가)
  • 화살표 방향 지정 — 8방향 격자 또는 왼쪽 탭의 방향 버튼(↗ / -)

화살표·결함표 추가 (통합 기능)

「화살표·결함표 추가」 하나로 같은 번호에 추가 화살표와 상태조사표 행(N-2, N-3…)을 함께 만듭니다. (구 「화살표 추가」+「결함표 추가」 통합)
  1. 결함 수정 창 → 화살표·결함표 추가 (모바일: 화살표·표).
  2. 창이 닫히고 핀 마킹 모드 → 도면에서 새 위치 클릭(또는 영역 그리기).
  3. 같은 NO. 박스에 화살표 추가 + 조사표 N-2 행 자동 생성.

번호·탭 표시 (7-1, 7-2 …)

  • 왼쪽 세로 탭: 7-1, 7-2, 7-3 … 형식만 사용 (예: 본번 7).
  • 각 탭 오른쪽 방향 버튼으로 해당 화살표 방향 지정.
  • 7-1 — 1번 화살표·대표 조사 데이터.
  • 7-2 — 2번 화살표 + 조사표 N-2 행 데이터.

도면 화살표 번호 (1·2…)

같은 번호에 화살표가 2개 이상이면 도면 화살표 옆에 1, 2, 3…이 표시됩니다. 화면 전용이며 PDF·한글 보고서 출력에는 포함되지 않습니다.

일괄 수정

도면에서 결함 2개 이상 선택 → 일괄 수정. 변경한 항목만 공통 적용됩니다.

전회차 미등록

엑셀·한글 가져오기로 전회차 데이터만 있을 때, 좌측 목록 전차 미등록에서 도면 배치(MARK 모드) 가능.

6. 상태조사표

조사표

  • 결함위치도 데이터와 자동 연동(번호, 위치, 부재, 종류, 규모, 진행·누수 등).
  • 같은 번호·여러 화살표: 표에는 N-1, N-2 … 행으로 분리.
  • 표 컬럼 설정 — 표시 열, 순서, 이름, 균열 크기 합침/분리.
  • 결함 직접 등록 — 도면 없이 행 추가.
  • 행 클릭 → 결함 수정 창 연동.

사진·앨범

  • PC/태블릿: 표 + 현장 결함 사진 앨범 분할 화면.
  • 중점관리 전·현차 비교(3종 건물).
  • 균열 게이지·팁 누적 측정 요약(NDT 연동).
  • 사진 탭 → 주석 드로잉(펜·화살표·원·텍스트).

7. 통계

  • 보기: 층별 / 층묶음 / 전체.
  • 필터: 상태양호 제외, 금회차만.
  • 요약: 조사 행 수, 결함 종류 수, 구조·비구조·마감 건수.
  • 구조 부재별 층별 최대 균열폭 — 기둥·보·슬래브·벽체 등, 번호 클릭 시 도면 이동.
  • 층별 결함 종류 매트릭스(균열 세부는 「균열」로 집계).

9. 보고서 출력 (PDF·한글·인쇄)

건축물 선택 후 헤더 또는 조사표 탭에서:

  • 미리보기 — 상태조사표·사진·위치도 통합 미리보기.
  • PDF 저장 — 조사표, 6장/페이지 사진, 위치도, NDT 결과.
  • 한글로 저장(시험) — HWPX 내보내기(1·2종 신가병원, 3종 칠산타워). 마킹 N / 표 N-1·N-2 분리, 15행·페이지(최대 17), 전경사진·균열 게이지 블록.
  • 인쇄 — 브라우저 인쇄.
  • 결함위치도 탭 벡터 PDF — 위치도만 벡터 출력.

10. 모바일·오프라인·팁

  • Android 앱은 GitHub Pages 최신 웹을 로드 — 배포 후 앱 재실행 또는 홈 새로고침.
  • 오프라인: 한 번 온라인으로 도면·3단계 해상도 캐시 후 현장에서 확대 가능.
  • 사진은 먼저 기기에 저장 후 백그라운드 업로드(온라인 시).
  • Esc → 선택 모드, D → 핀, A → 영역.
  • 캐드 핀: cad_defects_import.json → 캐드 핀 가져오기(PC).
주의: 같은 회사 계정으로 여러 기기 동시 작업 시 Firebase 동기화 지연이 있을 수 있습니다. 중요 저장 후 온라인 확인을 권장합니다.
