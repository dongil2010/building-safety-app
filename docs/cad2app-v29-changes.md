# CAD2APP v2.29 변경 설명

## 왜 바꿨나

### 1) v2.25 테두리 제외는 괜찮았음
사용자 확인: **v2.25**에서 글자 테두리 네모가 지시선으로 잡히지 않던 상태가 좋았다.  
닫힌 4변 LWPOLY·맞닿은 LINE 4개 거의-직사각 제외는 그 강도 그대로 되돌린다.

### 2) 이 도면만의 이중 평행변(~0.735mm)
일부 결함번호 테두리는 네 선만이 아니라 **좌/우(또는 상/하)에 평행선이 하나 더** 있다.  
간격은 약 **0.735mm**. v2.25만으로는 그 이중변이 후보에 남아, 글자에 제일 가까운 끝이 테두리 변이 될 수 있다.

그래서 **이중 평행변(gap ≤ 2.0)** 만 특수 케이스로 추가 제외한다.

### 3) v2.26~2.27 과필터는 다시 넣지 않음
그때는 미배정(원 못 찾음)이 **43개**까지 늘어났다. 아래는 넣지 않는다.

- LINE 4~8개 클러스터 통째 제외
- 글자 박스 둘레에 양 끝이 붙는 짧은 LINE 대량 제외
- away-leader / `minAwayGap` 하드 게이트

### 4) 매칭은 v2.28 단순 골격 유지
찾기 비율을 위해 매칭·가벼운 침묵 스왑은 v2.28을 그대로 둔다.

## 어떻게 바꿨나

### A. 테두리 제외 (v2.25 + 이중변만)

1. **닫힌 4변 LWPOLY** 거의-직사각형 → 후보 미등록 (v2.25와 동일)
2. **맞닿은 LINE 4개** 거의-직사각형 → 후보에서만 제외  
   - 이웃 끝점 공유 **정확히 2개**, 꼭짓점 **정확히 4개** (v2.25 강도 복구)  
   - `borderJoinTol` **15** (v2.25)
3. **평행 이중변** gap ∈ (0.05, 2.0] (0.735mm 포함)  
   - **같은** 글자 박스 근처·프레임 길이(박스 긴변×4 또는 하한 200)일 때만 **그 두 변만** 제외  
   - v2.28의 scale 1.5는 글자박스보다 큰 테두리 변을 놓쳐, 여유만 키움

객체는 지우지 않고 `lineList`에서만 뺀다.

### B. 매칭 (v2.28 유지)
1. 텍스트 실제 바운딩박스 → 제일 가까운 선 끝  
2. 반대쪽 끝 → 같은 도면층 CIRCLE  
3. 품질점수 → 1:1 그리디  

away-leader 없음. 미배정 폴백은 **LEADER만**.

### C. 침묵 스왑 (v2.28 유지, 가볍게만)
- **2-스왑**: 맞바꿈이 점수 합을 낮추면 그 쌍만 교체  
- **주황 표시**: 1·2등 점수 차가 `ambMargin`(80) 미만이거나 교차 패턴이면 색 62=30 (핀은 유지)

### D. 버전 표기
- 헤더 / 명령창: `v2.29`
- JSON `version`: `2.29_v25_rect_plus_double_edge`
